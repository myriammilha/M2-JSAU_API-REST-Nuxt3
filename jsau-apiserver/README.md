# jsau-apiserver

## Prérequis

Avant de lancer le projet, définissez la variable d’environnement suivante dans le dossier jsau-apiserver:

```bash
cd jsau-apiserver
export JSAU_REPOSITORY_FILE_PATH=~/Téléchargements/jsau-data
```

## Lancement
```bash
npm ci
npm run start
```
